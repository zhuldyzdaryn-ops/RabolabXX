Сравнение количеств теплоты при смешивании воды разной температуры

Цель работы

Определить количество теплоты, отданное горячей водой и полученное холодной при теплообмене, и объяснить причину их неравенства (потери тепла).

Формулы

Количество теплоты вычисляется по формуле: Q = c · m · Δt, где c = 4200 Дж/(кг·°C) — удельная теплоемкость воды. Из-за теплопередачи окружающим телам, Qотданное всегда немного больше, чем Qполученное.

Ход работы

  1. Установите параметры холодной воды (слева) и горячей воды (справа) с помощью ползунков. Объем воды в стаканах изменится автоматически.
  2. Нажмите кнопку «Смешать». Наблюдайте за процессом теплообмена и изменением показаний термометров.
  3. Дождитесь окончания анимации.
  4. Нажмите «Записать данные» для внесения параметров в таблицу.
  5. Самостоятельно рассчитайте Qпол и Qотд и впишите их в таблицу для построения графика.
